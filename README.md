# Geburtstags-Assistent für Android

Privates Android-Projekt für Geburtstage, Hochzeitstage und Ferien-Nachholerinnerungen. Quellcode wird über GitHub Actions auf einer Ubuntu-Umgebung gebaut. Die App sendet WhatsApp-Nachrichten **nicht automatisch**.

Der Android-Build ist erst bestätigt, wenn der GitHub-Actions-Workflow grün abgeschlossen ist.
